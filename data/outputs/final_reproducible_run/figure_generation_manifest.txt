FIGURE 2: figures/reviewer_cost_sensitivity.{png,pdf}
-----------------------------------------------------------------
Source artifact(s):
  - data/outputs/final_reproducible_run/final_canonical_metrics_audit.csv (cost_sensitive_loss,
    reviewer_workload_cases for MAGD-v2 and L2D-Standard)
  - data/outputs/final_reproducible_run/magd_v2_test_decisions.csv and
    decision_logs/learning_to_defer_decisions.csv (raw cross-check of reviewer-action counts)
Variables used: cost_sensitive_loss (=L_fraud), reviewer_workload_cases (=N_expert + 5*N_escalation).
Exact values/transformations:
  L_operational(c_R) = L_fraud + c_R * (N_expert + 5*N_escalation)
  MAGD-Fraud:   L_fraud=1011.482, reviewer_actions=73420
  L2D-Standard: L_fraud=1086.607, reviewer_actions=3627
  Break-even solved analytically (not hard-coded) from the canonical values:
    c_R* = (L_L2D - L_MAGD) / (actions_MAGD - actions_L2D) = 75.125 / 69793 = 1.0764e-03
    (matches the expected ~1.08e-03 to within 0.3%)
  c_R range plotted: [0, 2.5 * c_R*], i.e. [0, 2.69e-03].
  Figure explicitly states (in-figure italic note) that c_R is a relative loss-unit
  accounting-sensitivity parameter, not a monetary cost estimate.
Values calculated vs. directly loaded: L_fraud and reviewer_actions are directly loaded
  (and cross-checked against raw decision logs); the operational-loss curves and the
  break-even point are calculated from those loaded values.

FIGURE 3: figures/calibration_confidence_interaction.{png,pdf}
FIGURE 4: figures/calibration_neighbour_interaction.{png,pdf}
-----------------------------------------------------------------
Source artifact(s):
  - src/assurance/magd_v2.py (frozen, UNMODIFIED module: fit_final_v2_pipeline,
    apply_final_v2_pipeline, build_logistic_features, compute_wrong_confident_risk_v2)
  - data/outputs/model/{val,test}_predictions.csv, data/outputs/assurance/{distance_uncertainty,
    local_reliability,numerical_confidence}.csv (raw signal inputs, validation split only,
    used to reconstruct the model's fitting data)
  - data/outputs/final_reproducible_run/magd_v2_test_decisions.csv (verification target)
Model reconstruction and verification (scripts/frozen_v2_model_utils.py):
  The frozen v2 assurance model is NOT persisted anywhere as a standalone artifact
  (no pickled model file exists in the repo), so it is reconstructed by calling
  fit_final_v2_pipeline(validation_core) -- the exact frozen, deterministic entry
  point (fixed seed=42, fixed LogisticRegression hyperparameters C=1.0,
  class_weight="balanced") -- and then, BEFORE any plotting is allowed to proceed,
  applying it to the test split via apply_final_v2_pipeline and asserting the
  result reproduces the already-frozen `magd_assurance_risk` column in
  magd_v2_test_decisions.csv.
  Result: max abs diff = 1.11e-16 (floating-point epsilon) across all 96,843 test
  cases. This is proof the reconstruction is the frozen model, not a new fit.
Variables varied / held:
  Figure 3 varies calibration_risk_norm in [0,1] and confidence (numerical_confidence)
    in [0.5,1] (its natural domain, since numerical_confidence = max(score,1-score)).
    Held fixed at VALIDATION-DERIVED MEDIANS: distance_uncertainty_norm=0.500,
    neighbor_error_rate_norm=0.000.
  Figure 4 varies calibration_risk_norm in [0,1] and neighbor_error_rate_norm in [0,1].
    Held fixed at validation medians: distance_uncertainty_norm=0.500, confidence=0.996.
  Note: calibration_risk_norm and neighbor_error_rate_norm both have a validation
  median of exactly 0.000 because of heavy point-mass at the well-calibrated /
  zero-neighbour-error majority class -- this is a genuine, verified property of
  the validation data (not a bug), and is itself a meaningful "typical case"
  reference point.
  Grid: 120x120, wrong_confident_risk_v2 recomputed at each grid point via the
  frozen compute_wrong_confident_risk_v2 (beta_calibration=beta_neighbor=0.5, the
  frozen pipeline's own defaults), then the frozen 7-feature vector is built
  (build_logistic_features formula) and scored with model.predict_proba -- the
  exact same frozen LogisticRegression object verified above. Nothing is refit.
  Both figures share one colour scale: vmin=0.3968, vmax=0.9825 (min/max across
  both grids combined), so they are directly comparable side by side.
Values calculated vs. directly loaded: the model and its coefficients are loaded
  (reconstructed + verified, not refit); the risk surface at each grid point is
  calculated by evaluating that frozen model.
Caption requirement: both figures state in-figure ("Partial fitted-model
  interpretation (frozen MAGD-Fraud logistic assurance model) -- not a causal
  effect.") that this is a partial-dependence-style reading of the frozen fitted
  model, not a causal claim.
Figure data CSVs: data/outputs/final_reproducible_run/figure_data/calibration_confidence_interaction_plot_data.csv,
  data/outputs/final_reproducible_run/figure_data/calibration_neighbour_interaction_plot_data.csv
