## Reading The Tables

- Dataset and AI-assurance tables describe the benchmark setting and the signal stack.
- Baseline and human-AI metrics tables compare MAGD-Fraud with threshold, defer-to-expert, and oracle references.
- Ablation tables show which evidence sources matter most.
- Auditability and statistical tables support the paper’s traceability and significance claims.

## Notes

- `data/outputs/paper_tables/table_manifest.json` lists the generated paper-table bundle.
- The same tables may be regenerated by `scripts/run_full_magd_experiment.py`.
- Some supporting files are only meaningful when the corresponding stage was enabled or available in the data.
